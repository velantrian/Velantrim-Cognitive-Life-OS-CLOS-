This repository is a **research blueprint**, not an implementation repository by default.

Before changing anything, read in order:

1. `README.md`
2. `docs/CURRENT_STATUS.md`
3. `docs/CLOS_BLUEPRINT.md`
4. `docs/EVIDENCE_LEDGER.md`
5. `docs/DISCRIMINATING_FIXTURES.md`

7. `docs/RESEARCH_SURFACES.md`

## Core operating boundary

```text
RESEARCH ≠ CANON
CANON ≠ IMPLEMENTATION AUTHORIZATION
IMPLEMENTATION ≠ RUNTIME AUTHORIZATION
MODEL OUTPUT ≠ EVIDENCE
CI GREEN ≠ SEMANTIC PROOF
```

Do not create code, runtime wiring, agents, schedulers, databases, RAG pipelines, graphs or new modules merely because a research phenomenon has a name.

## Default research process

```text
DON'T INVENT
→ CROSSWALK
→ FIND RESIDUAL GAP
→ FORMULATE OBSERVABLE FAILURE
→ TRY TO DESTROY THE GAP
→ BOUNDED FIXTURE
→ RESULT
→ MERGE / REFINE / REJECT
→ ONLY THEN CONSIDER ARCHITECTURAL CHANGE
```

## Primitive admission test

A proposed new construct should demonstrate:

1. distinct function;
2. distinct state/transition consequence;
3. material non-expressibility using existing concepts;
4. observable failure without it;
5. falsifier;
6. substrate-neutral usefulness;
7. discriminating fixture.

```text
REAL PHENOMENON ≠ ARCHITECTURAL GAP
REAL GAP ≠ NEW PRIMITIVE
NICE NAME ≠ NEW MODULE
```

## Evidence discipline

Every material research claim should preserve where practical:

- source / provenance;
- evidence class;
- what the evidence supports;
- what it does not prove;
- competing explanation;
- uncertainty;
- current disposition;
- falsifier / downgrade condition;
- next discriminating fixture.

Biological and psychological mechanisms are not automatically digital architecture.

```text
BIOLOGICAL OBSERVATION
→ COMPETING EXPLANATIONS
→ FUNCTIONAL INVARIANT?
→ CLOS CROSSWALK
→ RESIDUAL GAP?
→ FIXTURE
→ DECISION
```

## Status-changing edits

An edit is status-changing if it:

- promotes or demotes a research candidate;
- introduces a new architectural claim;
- changes an authority boundary;
- claims a new primitive/module/owner;
- changes a current research disposition;
- states that evidence established a result previously marked uncertain/open.

For such edits, prefer:

```text
research / crosswalk
→ source-pinned evidence
→ proposed result + proposed diff
→ adversarial review
→ operator decision
→ write
→ post-write currentness verification
```

A reviewer is advisory. Agreement between several AI systems does not create independent scientific evidence.

## Preserve Meaning Envelope

Across summarization, compression, reconstruction and transfer, preserve or explicitly qualify loss of:

- semantic role;
- source / ownership;
- scope / conditions;
- time / currentness;
- uncertainty / UNKNOWN;
- revision / supersession history;
- authority / constraint.

## Ecosystem boundary

This repository may research cross-project cognitive requirements, but it does not own every resulting change.

Use `docs/ECOSYSTEM_CROSSWALK.md` before proposing changes to Crystal, Titan, Native Kernel, Mentaury Soul, Continuum or Mentaury-Kernel.

Never assume a CLOS finding automatically authorizes edits in a sibling repository.

## Prohibited drift without explicit operator authorization

Do not:

- declare CLOS final Canon;
- claim consciousness/sentience/AGI;
- create a new runtime;
- assign CLOS production authority;
- turn a research label into a required module;
- choose mandatory implementation technology;
- silently rewrite historical checkpoints;
- erase rejected alternatives or corrections;
- merge sibling-project authority into this repository.

When evidence is insufficient, `UNKNOWN` is a valid result.
