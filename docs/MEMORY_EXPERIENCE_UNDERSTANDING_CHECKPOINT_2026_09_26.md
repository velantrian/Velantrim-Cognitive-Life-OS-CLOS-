## 8. 2026-09-27 refinement — human state, continuity, and conditional learned influence

Status: `RESEARCH REFINEMENT · NOT CANON · NOT RUNTIME AUTHORIZATION · NO NEW MODULE · NO NEW EXPERIMENT ID`

### Human-state qualification

New strong boundary:

`PLAUSIBLE HUMAN STATE ≠ ESTABLISHED HUMAN STATE`

A dialogue may support a bounded speech/discourse act without establishing the hidden motive behind it. Preserve these distinctions:

- `TRY ≠ FULL ENDORSEMENT`
- `PERMISSION ≠ AGREEMENT`
- `STOP DISCUSSION ≠ REJECT PROPOSITION`
- `POSSIBLE FATIGUE / FEAR / CAPITULATION ≠ FACT OF FATIGUE / FEAR / CAPITULATION`
- `UNSELECTED ≠ REJECTED`
- `DISCUSSION ≠ COMMITMENT`

Latent motive may legitimately remain `UNKNOWN / NOT DETERMINABLE FROM AVAILABLE EVIDENCE`.

Reference-state boundary:

`TRANSCRIPT-SUPPORTED STATE ≠ RETROSPECTIVE USER SELF-REPORT ≠ MODEL-EXPOSED ADJUDICATION`

A later self-report is relevant evidence about the user's later account, but it does not retroactively prove that the earlier visible dialogue made the hidden state inferable.

### Exploratory Grok dialogue

The phrase-reading dialogue is retained only as:

`EXPLORATORY_DONOR · MODEL-EXPOSED · NOT BLIND · NOT GOLD · FAILURE-SEED SET`

Useful failure seeds include:

- `POSITIVE_EVALUATION → SELECTION`
- `TRIAL_AUTHORIZED → SELECTED`

- `STOP_DISCUSSION → PROPOSITION_REJECTED`
- `POSSIBLE_MOTIVE → MOTIVE_FACT`

This material must not be promoted into U0/U0b gold.

### TCE / Continuum decomposition

Evaluate three questions independently:

1. `STATE EXTRACTION` — was the source conversation represented correctly?
2. `STATE TRANSFER` — did snapshot / interruption / restore preserve that state?
3. `CONTINUATION UTILITY` — did the restored state support correct continuation?

Therefore:

- `GOOD CONTINUATION ≠ CORRECT SNAPSHOT`
- `GOOD RESUME ≠ CORRECT EXTRACTION`
- `WRONG STATE + GOOD CONTINUATION ≠ SUCCESS`

Important failure pattern:

`FALSE EXTRACTION → FALSE SNAPSHOT → BEHAVIOR CONSISTENT WITH FALSE SNAPSHOT → FALSE PASS`

Working analytical label: **SELF-CONFIRMING SNAPSHOT ERROR**. This is not a formal enum.

For a non-selection case, preserve:

- current goal only when source-supported;
- live alternatives;
- `USER SELECTION = NONE / NOT ESTABLISHED`;
- only explicit rejections;
- only explicit deferrals;
- critical unknowns;
- a resume point that does not choose on behalf of the user.
