# 🗂️ CLOS Research Surfaces

```text
Status: DOCUMENTATION BOUNDARY
Purpose: prevent current-state / archive / authority conflation
```

CLOS currently uses three complementary documentation surfaces.

## 1. GitHub — versioned research repository

This repository is the portable, reviewable GitHub home for CLOS.

Use it for:
- current compact architecture;
- explicit status files;
- evidence ledgers;
- bounded fixtures;
- ecosystem crosswalks;
- reviewable changes and historical diffs;
- agent instructions.

GitHub presence does not itself promote research into Canon or runtime authority.

## 2. Notion — live current research wording

Page: **⚗️ Velantrim Cognitive Life OS 📖**

Role:
- active current wording;
- live research checkpoint;
- working architectural navigation;
- current status of research candidates and dispositions.

During the current bootstrap period, a freshly verified live Notion checkpoint remains the best current-wording reference if a stale GitHub/Google Docs paragraph conflicts with it.

## 3. Google Docs — detailed rationale and research history

Document: **⚗️ Velantrim Cognitive Life OS 📖**

Role:
- detailed explanations and comments;
- WHY each distinction matters;
- competing explanations;
- rejected formulations and why they were rejected;
- source/evidence context;
- longitudinal AI/Rosebud observations;
- research trajectory and historical checkpoints.

The Google document intentionally preserves more history than a compact GitHub blueprint.

## 4. Preservation rule

```text
CURRENT ARCHITECTURE ≠ RESEARCH ARCHIVE
SUMMARY MAY ORIENT
SUMMARY MUST NOT DESTROY THE PATH BY WHICH STATUS WAS EARNED
REVISION ≠ SILENT OVERWRITE
HISTORY ≠ CURRENT STATE
```

A compact GitHub claim should be traceable to fuller rationale/evidence where material.

## 5. What should be copied where

| Information | GitHub | Notion | Google Docs |
|---|---:|---:|---:|
| current compact blueprint | ✅ | ✅ | ✅ checkpoint |
| current candidate status | ✅ | ✅ primary live wording | ✅ history-preserving |
| fixtures / falsifiers | ✅ | ✅ when active | ✅ with commentary |
| evidence classification | ✅ | ✅ summary | ✅ detailed |
| long rationale / discussion history | link/curated | selective | ✅ primary |
| rejected alternatives | ✅ material ones | ✅ if current relevance | ✅ detailed |
| runtime implementation | only if later explicitly authorized | not authority by default | commentary only |

## 6. Current placement change

A dedicated CLOS GitHub repository now exists. This supersedes the earlier idea that Mentaury Soul should serve as the primary GitHub research home.

The conceptual ownership boundary remains unchanged:

- Mentaury Soul still owns cognition/identity-domain consequences it explicitly adopts;
- other Velantrim projects retain their own project-local authority;
- the dedicated CLOS repository holds cross-project research, not automatic downstream authority.
